# HeartWatch
ECE Senior Project (2026)
by Bobby Lofgren, Carson Ord, Dylan Malinis, and Zachary Osada

### Toolchain setup

1. Install the extension PlatformIO for VSCode (if you don't already have it)

2. Open the `HeartWatch` folder in PlatformIO and let it set up the project using the `platformio.ini` file

### Flashing the board

Build the project by using the `Build` option in PlatformIO

Flash the board by using the `Upload` option in PlatformIO
